# Server apps: releases

Built apps for Spoty, Glance and Butterfly, published by the Release workflow in the private `personal-apps` repo.
Nothing here is edited by hand.

- `updates.json`: what the apps' in-app updater reads.
- `altstore-source.json`: add this URL once in SideStore or AltStore to get the iPhone builds and their updates:
  `https://raw.githubusercontent.com/hamuelpalallos/server-apps-release/main/altstore-source.json`
- The files themselves are attached to the releases (Releases tab).
